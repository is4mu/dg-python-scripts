# Open Batch

- **Package**: `open_batch`
- **Menu**: Media Panel → **DG: Batch** → Open
- **Flame**: 2025+

## できること

閉じている Batch グループを開きます（選択した PyBatch、または Desktop 配下）。

## 使い方

1. Batch グループまたは Desktop を選択
2. **DG: Batch → Open**

## 注意

- 既に開いている Batch の扱いは Flame 側の状態に依存する
