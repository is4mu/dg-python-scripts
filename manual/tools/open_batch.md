# Open Batch

- **Package**: `open_batch`
- **Menu**: Media Panel → **DG: Batch** → Open
- **Flame**: 2025+

## What it does

Opens closed Batch groups (selected PyBatch or under the Desktop).

## How to use

1. Select a Batch group or Desktop
2. **DG: Batch → Open**

## Notes

- Behavior for already-open Batches depends on Flame state
