# Resize All Clips

- **Package**: `batch_resize_clips`
- **Menu**: Media Panel → **DG: Clip** → Resize All Clips
- **Flame**: 2025+

## できること

複数クリップ用に、マスター Resize と mimic_link でつながったリサイズ Batch を作成します。

## 使い方

1. クリップを複数選択
2. **DG: Clip → Resize All Clips**

## 注意

- リサイズノードが mimic で連動する前提のワークフロー向け
