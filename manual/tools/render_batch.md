# Render Batch

- **Package**: `render_batch`
- **Menu**: Media Panel → **DG: Batch** → Render
- **Flame**: 2025+

## What it does

Renders the selected Batch group.

## How to use

1. Select a Batch
2. **DG: Batch → Render**

## Notes

- Render settings and output depend on Batch / Flame project configuration
