# Render Batch

- **Package**: `render_batch`
- **Menu**: Media Panel → **DG: Batch** → Render
- **Flame**: 2025+

## できること

選択した Batch グループをレンダーします。

## 使い方

1. Batch を選択
2. **DG: Batch → Render**

## 注意

- レンダー設定・出力先は Batch / Flame プロジェクト設定に依存
