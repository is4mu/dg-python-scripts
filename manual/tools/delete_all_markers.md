# Delete All Markers

- **Package**: `delete_all_markers`
- **Menu**: Media Panel → **DG: Sequence** → Delete All Markers
- **Flame**: 2025+

## できること

選択クリップ／シーケンス上のマーカーをすべて削除します。

## 使い方

1. 対象を選択
2. **DG: Sequence → Delete All Markers**

## 注意

- 取り消しは Flame の Undo に依存。実行前に対象を確認
