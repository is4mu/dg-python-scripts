# Audio Lock

- **Package**: `audio_lock`
- **Menu**: Media Panel → **DG: Audio** → Lock / Unlock Audio Tracks
- **Flame**: 2025+

## What it does

Locks and unlocks audio tracks.

## How to use

1. Select targets
2. **Lock Audio Tracks** or **Unlock Audio Tracks**

## Notes

- Lock state depends on sequence layout
