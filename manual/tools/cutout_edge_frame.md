# Cutout Edge Frame

- **Package**: `cutout_edge_frame`
- **Menu**: Media Panel → **DG: Sequence** → Cutout First Frame / Cutout Last Frame
- **Flame**: 2025+

## できること

シーケンスの先頭または末尾フレームをカットアウトします。

## 使い方

1. シーケンスを選択
2. **Cutout First Frame** または **Cutout Last Frame**

## 注意

- Timeline コンテキストが必要な場合がある
