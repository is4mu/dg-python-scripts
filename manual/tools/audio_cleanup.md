# Audio Cleanup

- **Package**: `audio_cleanup`
- **Menu**: Media Panel → **DG: Audio** → Only 1-2 Track / Only 3-4 Track / Delete Mute Tracks / Delete All Audio Tracks
- **Flame**: 2025+

## できること

オーディオを 1-2 のみ・3-4 のみに残す、ミュート削除、全オーディオ削除などを行います。

## 使い方

1. 対象を選択
2. 目的の項目を実行

## 注意

- **Delete** 系は破壊的。実行前に確認
