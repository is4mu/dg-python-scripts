# Set Start Frame to 1

- **Package**: `set_start_frame_1`
- **Menu**: Media Panel → **DG: Clip** → Set Start Frame to 1
- **Flame**: 2025+

## できること

選択クリップのスタートフレームを 1 に設定します。

## 使い方

1. クリップを選択
2. **DG: Clip → Set Start Frame to 1**

## 注意

- タイムコード運用中のクリップでは意図を確認してから実行
