# List Plugins

- **Package**: `list_plugins`
- **Menu**: DGpy → List Plugins
- **Flame**: 2025+

## できること

現在の Desktop で使われている OpenFX / Sparks を一覧します（バッチ内・タイムライン FX）。

## 使い方

1. **DGpy → List Plugins**
2. 表示されたリストを確認する

## 注意

- BFX 内などで検出できないケースがある
- プラグインの有無そのものではなく「使用箇所の洗い出し」向け
