# Color

- **Package**: `color`
- **Menu**: Media Panel 等 → **DG: Color** → 色名（Rose / Red / …）
- **Flame**: 2025+

## できること

選択オブジェクトのカラーラベルを、10 色のミュートパレットから設定します。

## 使い方

1. フォルダ・リール・クリップなどを選択
2. **DG: Color** → 目的の色

## 注意

- 色名はメニュー表示どおり（Rose, Red, Orange, Gold, Green, Teal, Blue, Purple, Black, Gray）
