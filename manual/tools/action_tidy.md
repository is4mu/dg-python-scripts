# Action Tidy

- **Package**: `action_tidy`
- **Menu**: Media Panel / Action → **DG: Segment** → Clean Up Action / (Fit) / Toggle Fit Method / Strip Expressions
- **Flame**: 2025+

## できること

Action セグメントの整理、Fit 切替、Expression 除去を行います。

## 使い方

1. 対象セグメント／クリップを選択
2. **DG: Segment** から目的の操作

## 注意

- Clean Up はノード／接続に影響する。重要な Action は事前に複製を推奨
