# Save Batch Setup

- **Package**: `save_batch_setup`
- **Menu**: Media Panel → **DG: Batch** → Save Setup
- **Flame**: 2025+

## できること

Batch セットアップを指定フォルダへ保存します（既定は project の batch/flame 付近）。

## 使い方

1. 対象 Batch を選択
2. **DG: Batch → Save Setup**
3. 保存先を確認して実行

## 注意

- 上書きや既存ファイルの扱いはダイアログ／ログを確認
