# Go To Frame

- **Package**: `goto_frame`
- **Menu**: Media Panel → **DG: Clip → Go To** → First Frame / Last Frame / In Mark / Out Mark / Custom Frame...
- **Flame**: 2025+

## できること

クリップの再生ヘッドを指定フレームへ移動します。

## 使い方

1. クリップを選択
2. **DG: Clip → Go To** から目的の項目
3. Custom の場合はフレームを入力

## 注意

- In/Out マークが無い場合の挙動は実装・Flame 状態に依存
